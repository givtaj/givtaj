I design **backend systems and APIs** for healthcare and worker benefits at **Workers Benefit Fund**. Outside work, I build open-source tools for testing APIs, debugging browser requests, and tracing services at runtime.
I also build interactive lessons that help developers see how software works under the hood.

# Selected projects

🧭 **[Daedlo](https://daedlo.com/)** — Model a user flow in Rust, run it locally with Playwright, and inspect the evidence that an action worked, down to whether a save actually persisted. [GitHub](https://github.com/givtaj/daedlo)

🪐 **[SeeRunTime](https://seeruntime.com/)** — Step through interactive 3D lessons to see how the Node.js event loop handles callbacks or how Rust’s Tokio runtime schedules tasks.

---

- ⏱️ **[SleepAPI](https://github.com/givtaj/sleepapi)** — Give an HTTP client slow responses, dropped connections, or two `503`s followed by a `200` to see how its timeouts and retries behave.
- 📊 **[rusta-pitest](https://github.com/givtaj/rusta-pitest)** — Check HTTP endpoints from the command line and measure latency and throughput under concurrent load.
- 🚦 **[Stoplight](https://github.com/givtaj/stoplight)** — Pause an outgoing API request in a Chrome tab, inspect or edit its headers and body, then let it continue. **[Add to Chrome](https://chromewebstore.google.com/detail/stoplight/hmiegichaapkmpplleopipdbpdfafhpk)**
- 🔬 **[ebpf-tracker](https://github.com/givtaj/ebpf-tracker)** — Capture Linux system calls from a Rust service running in Docker, then replay the trace to inspect file opens and connection attempts.
